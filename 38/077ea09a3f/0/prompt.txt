# `/shape:pr-prepare` skill: writes What/Why/Focus body and routes PRs to auto-merge or human review

## What

A new skill `/shape:pr-prepare` exists in `agent-skills-shaper` that reads stack PRs, writes a structured What/Why/Focus body on each, decides auto-merge vs human-review per the carve-out rule, and records the routing decision in `prep_verdict`.

## Why

This is the PR Preparer role. Without it, PRs from drained tickets carry no structured context: reviewers parse intent from the diff alone, auto-mergeable changes get unnecessary human review, and KR3 cannot be satisfied.

## Assumptions

* Stack PRs are readable via the Graphite MCP; PR bodies are writable via the same.
* Carve-out rule: small change + no critical focus items → auto-merge via Graphite native mechanism; otherwise → human-review.
* `prep_verdict` shape: `{result: "structured"|"auto-merge", route: "human-review"|"auto-merge", reasoning: "..."}`.

## Key Risks

* Graphite MCP PR-read and PR-body-write APIs must be verified against actual Graphite docs before implementing — the interface may differ from assumed.
* The auto-merge carve-out rule may be miscalibrated — auto-merging a risky change leaves the operator with no fallback.

## Definition of Done

* The skill exists in `agent-skills-shaper` and is registered.
* Given a stack with a small, low-risk PR: produces auto-merge label and records `prep_verdict.route: "auto-merge"`.
* Given a stack with a human-review PR: writes a What/Why/Focus body and records `prep_verdict.route: "human-review"`.
* `prep_verdict` schema matches the spec.
