# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful. The artefacts in this pack are opinionated, and disagreements about the opinions are welcome — keep the disagreement on the artefact, not on the person.

To report a violation, open a private issue or contact the maintainer at the email listed in the GitHub profile.
